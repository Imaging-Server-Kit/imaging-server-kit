# AI policy

*Imaging Server Kit* is being developed with passion and intent by humans, with the occasional help of AI to **improve the overall quality of the project**. The table below summarizes the respective contributions of humans and AI agents within the project.

| Human contributions |
| ----- |
| Conceptualization of the project |
| Implementing core functionalities (public API) |
| Deciding which features to prioritize |
| Writing the initial documentation site |
| Reviewing and validating AI-generated outputs |
| Reviewing tests and testing the package on real scientific data |

| AI contributions |
| -- |
| Catching and fixing bugs |
| Identifying series of actions that lead to unexpected results |
| Targeted refactoring to improve code clarity or maintainability |
| Enhancing the documentation site |
| Writing or fixing public docstrings |
| Writing tests and testing the package on toy scientific data |
